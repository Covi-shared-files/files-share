# 人工智能

[返回首页](../README.md) · [完整资源目录](../docs/CATALOG.md) · [下载说明](../docs/DOWNLOAD.md)

本分类收录机器学习、神经网络、深度学习教材及论文。以下是阅读方向建议，并非对每份 PDF 的版本、译文或质量作出的认证。

## 怎么开始

| 目标 | 建议入口 | 前置知识与阅读方式 |
| --- | --- | --- |
| 了解神经网络与深度学习 | [Neural Network and Deep Learning 中文文件](<./Neural Network and Deep Learning-ch.pdf>)、[英文文件](<./Neural Networks and Deep Learning-eng.pdf>) | 建议先掌握微积分、线性代数和基础编程，结合小例子阅读 |
| 系统学习机器学习 | [机器学习（周志华）](./机器学习_周志华.pdf) | 建议具备概率统计、线性代数基础，配合习题学习 |
| 进一步学习深度学习 | [DeepLearningBook](./网络整理/1.0/DeepLearningBook.pdf)、[同目录中文文件](<./网络整理/1.0/深度学习(Deep Learning) Yoshua Bengio & Ian GoodFellow中文版.pdf>) | 建议先掌握机器学习基础，按目标章节阅读 |
| 阅读专题论文 | [网络整理](./网络整理) | 先确定研究主题，再核对论文题目、作者、年份与版本 |

建议顺序：补足数学与编程基础 → 选择一本入门教材 → 完成小规模实践 → 按具体问题查论文。无需同时通读所有教材。

## 关于论文编号目录

`网络整理/1.0` 至 `网络整理/3.8` 沿用现有目录编号，目前没有足够信息将每个编号可靠地命名为某个专题。可以通过[完整资源目录](../docs/CATALOG.md)查找文件名或论文编号。

欢迎核对原文后补充各组的主题、论文标题、作者、年份、简短介绍和原始链接。仅凭文件名推测的对应关系，应先核实再填写。
