# 来源与授权信息

[返回首页](../README.md) · [贡献指南](../CONTRIBUTING.md)

## 当前状态

现有文件缺少逐项来源和授权记录。[完整资源目录](./CATALOG.md)将未核实的条目标记为“待补充”，不根据文件名推定作者授权、开放获取状态或再分发许可。

根目录的 [LICENSE](../LICENSE) 保留原有内容。它不应被用作第三方教材、论文或软件的授权证明。使用和分享第三方资料前，请查阅作者、出版方或项目官方给出的条款。

## 每项资源需要补充什么

| 字段 | 内容 |
| --- | --- |
| 标题与版本 | 以资料正文、作者主页或出版信息核实 |
| 作者或机构 | 标注原作者，以及适用时的译者、整理者 |
| 原始来源 | 作者主页、出版社页面、论文原站或项目官方仓库的具体页面 |
| 授权依据 | 明确的许可证、使用条款或授权说明链接；不确定时写“待确认” |
| 获取方式 | 原始链接或经核实可再分发的文件；付费与免费获取应如实区分 |
| 核验记录 | 核验日期、核验内容以及仍未解决的问题 |

公开可访问、免费阅读和允许再分发是不同信息，应分别记录。请不要仅凭“网上能下载”填写开放许可证。

## 新增资料的处理方式

优先提交原始来源链接、简介、阅读笔记与练习记录。需要上传第三方文件时，先补充可再分发的依据；无法确认时，先提交书目信息和原始页面链接，交由维护者核实。

对既有资料，本次整理只补充导航和待核实状态，没有完成逐份授权核验，也没有替换现有许可证。

## 发现来源或权利问题

请向维护者提供资料路径、原始来源、问题说明和可公开的依据，可通过 [Issue](https://github.com/Covi-shared-files/files-share/issues)提出。不要在公开 Issue 中上传身份证件、私人联系方式或私密授权文件；需要非公开处理的信息请使用维护者另行提供的渠道。
