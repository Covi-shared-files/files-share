## 阅读方向

学习编程基础后，可以从[数据结构与算法分析（C 语言描述）](./Algorithm/PDF/数据结构与算法分析：C语言描述.pdf)或[Java 版](<./Algorithm/PDF/数据结构与算法分析(Java版).pdf>)选择适合自己语言的一本。进一步学习时，可按具体主题查阅[算法导论](./Algorithm/PDF/算法导论.pdf)。

工具清单和配置包含贡献者的个人习惯，不要求全部安装，也不保证适用于所有环境。欢迎补充版本要求、安装步骤和实际使用经验。
