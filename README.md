# 共享资源库

来自 Q 群 **Covi的技术神殿（832350428）** 的学习资料与工具配置分享。话题包括嵌入式、计算机、编程、建模、网络开发等，我们期待会用 GitHub 和 Linux 的开发者一起交流、整理资料。

## 从这里开始

- 想按方向找资料：查看下面的分类导航。
- 想找某本书或某篇论文：打开[完整资源目录](./docs/CATALOG.md)，使用浏览器查找标题、文件名或论文编号。
- 想下载文件：先读[下载与 Git LFS 说明](./docs/DOWNLOAD.md)。只需要一本书时，可以进入文件页面单独下载。
- 想分享资料或纠错：阅读[贡献指南](./CONTRIBUTING.md)。补充简介、来源和阅读笔记同样欢迎。

## 如何选择资料

先按自己的学习目标选一本主教材，再按需查阅其他材料。分类页提供阅读方向建议；具体书目、版本和语言仍需以文件内容为准，文件名不能替代内容核验。

AI 论文目录保留了原有编号结构，部分编号尚缺主题说明。欢迎在核对内容后补充标题、摘要和原始链接，帮助后来者理解每组资料。

## 来源与使用说明

本仓库包含第三方教材、论文及贡献者提供的清单、配置。**“可以下载”不代表“已经获得开放授权”。** 各项资料的来源和授权仍需逐项补充，具体状态见[来源与授权说明](./docs/SOURCES.md)。

仓库根目录保留现有 [LICENSE](./LICENSE)。对于第三方内容，请核对其作者或出版方提供的使用条款；不要将根目录许可证当作第三方资料的授权证明。

如果发现链接失效、分类错误、资料重复或来源问题，请通过 [Issues](https://github.com/Covi-shared-files/files-share/issues) 提供对应路径和说明。
