## 阅读建议

面向机器学习或计量经济学，可以优先补足线性代数、微积分和概率统计；面向算法，可以优先学习离散数学和图论。实分析、复分析、抽象代数等材料可在具备相应基础后按兴趣进阶。

这些建议用于选择方向。教材的具体版本、语言、完整性和来源仍需核实，详见[完整资源目录](../docs/CATALOG.md)与[来源说明](../docs/SOURCES.md)。
